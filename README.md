# OpenVM RV64 Recompiler Verification

A small, reproducible research project studying semantic preservation in OpenVM's RV64
native recompiler.

## Current scope

We study the RV64I 32-bit "W" arithmetic family:

- `ADDW`
- `SUBW`
- `SLLW`
- `SRLW`
- `SRAW`

The project compares three layers:

1. RV64 instruction semantics.
2. The semantics of the C expressions emitted by OpenVM's RVR backend.
3. A Lean model with machine-checked semantic-preservation theorems.

The initial target is deliberately narrow. This repository does **not** claim to verify
Clang, all of OpenVM, the proof system, or the zkVM end to end.

## Research question

For the pinned OpenVM revision, do the emitted C expressions for RV64I `W` operations
preserve the corresponding RV64 architectural semantics for all 64-bit source operands?

## Reproducibility rule

Every result intended for the paper must be generated by a checked command and recorded
under `results/`. No benchmark or theorem claim enters the paper before deterministic
verification passes.
